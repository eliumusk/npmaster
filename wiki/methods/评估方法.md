# 评估方法

## 评估指标

### 主指标
- **AUROC**：受试者工作特征曲线下面积（threshold-independent，最稳健）
- **F1**：precision和recall的调和平均
- **Precision/Recall**：互补评价假阳性和假阴性

### 辅助指标
- **Accuracy**：在平衡数据集上参考
- **PR-AUC**：在类别不平衡场景下比AUROC更敏感（本项目train/test基本平衡，没重点看）

## 置信区间（95% CI）

**必须用 BGC 级 cluster bootstrap**，不能用窗口级。

```python
def cluster_bootstrap(y_true, y_prob, sources, n_boot=5000):
    source_to_idx = defaultdict(list)
    for i, src in enumerate(sources):
        source_to_idx[src].append(i)
    source_keys = list(source_to_idx.keys())
    n_sources = len(source_keys)
    aurocs = []
    for _ in range(n_boot):
        boot_keys = np.random.choice(source_keys, n_sources, replace=True)
        boot_idx = []
        for k in boot_keys:
            boot_idx.extend(source_to_idx[k])
        yt = y_true[np.array(boot_idx)]
        yp = y_prob[np.array(boot_idx)]
        if len(np.unique(yt)) < 2:
            continue
        aurocs.append(roc_auc_score(yt, yp))
    return np.percentile(aurocs, 2.5), np.percentile(aurocs, 97.5)
```

详见 [[../concepts/Cluster-Bootstrap]]。

### 参数
- `n_boot=5000`：足够稳定
- `source_keys`：BGC id（正样本）或基因组GCF id（负样本）

## 验证实验（Sanity Checks）

每次关键结果都要做：

### N-padding 检查
- 只用N序列的embedding，看AUROC是否~0.50
- 结果：AUROC全部~0.50 ✓（无N-shortcut）

### 随机标签 baseline
- 把训练集y打乱，重新训练，看AUROC
- 结果：~0.50 ✓（确实在学信号）

### GC bias 检查
- 正负样本GC均值差异 < 0.02 ✓
- 详见 [[../concepts/GC偏差]]

### 反向互补一致性（未做）
- DNA是双链，正向和反向互补应该给出相同预测
- 未做，是将来的改进方向

## 测试策略

### 同属测试
- train/val/test 按 BGC 和 genome 分组
- 评估用 test split

### 跨属测试（泛化评估）
- train 固定用 Strep 数据
- test 用其他属的全量数据（合并train+val+test）
- 理由：小属BGC数量不足，不要做固定split

详见 [[../data/多属数据集]]。

## 报告格式

正确：
```
AUROC=0.926 [0.893, 0.952] (BGC-level cluster bootstrap, n_boot=5000)
测试集: 562 positive windows from 51 BGCs, 562 negative windows from 11 genomes
```

错误：
```
AUROC=0.926  # ❌ 没有CI，没有样本数
```

## 常见陷阱

1. **窗口级bootstrap** → CI被严重低估
2. **10% test split in 小属** → 测试集只有2-5个独立BGC，统计不可靠
3. **不报告独立样本数** → 读者无法判断结果可信度
4. **"我说了这个问题"** ≠ "我分析了这个问题"（参见 [[../experiments/首次验证实验]] 的教训）
