# 分类器

## 当前主力：Random Forest

```python
from sklearn.ensemble import RandomForestClassifier

clf = RandomForestClassifier(
    n_estimators=100,
    max_depth=20,
    random_state=42,
    n_jobs=-1
)
clf.fit(X_train, y_train)
y_prob = clf.predict_proba(X_test)[:, 1]
```

**参数选择**（默认，未做grid search）：
- `n_estimators=100`：足够，更多无明显提升
- `max_depth=20`：限制过拟合，在4096维空间合理
- `random_state=42`：固定复现

## 对比实验（w8192，105 genome数据集）

| 方法 | AUROC | F1 | Rec |
|---|---|---|---|
| k-mer + LR | 0.658 | 0.593 | 0.592 |
| k-mer + RF | 0.893 | 0.790 | 0.745 |
| Evo2 + LR | 0.904 | 0.832 | 0.835 |
| **Evo2 + RF** | **0.940** | **0.879** | 0.864 |
| Evo2 + GBT | 0.941 | 0.874 | 0.856 |
| Evo2 + MLP(256,128) | 0.938 | 0.879 | **0.918** |
| Evo2+kmer + RF | 0.941 | 0.877 | 0.859 |

（旧25-genome数据集结果，详见 [[../experiments/首次验证实验]]）

## 观察

### 1. RF 是 Evo2 embedding 的最佳搭档
- 在4096维空间中，RF能捕捉非线性决策边界
- 比 LR 提升约 +0.04 AUROC
- 训练时间1-2分钟，推理极快

### 2. Evo2+kmer 合并没有额外收益
- Evo2 embedding已经包含k-mer能捕捉的所有信息
- 证明 Evo2 学到了更深层的表示

### 3. MLP 的 Recall 更高但 AUROC 类似
- MLP(256,128): AUROC=0.938, Recall=**0.918**
- 适合"宁可多报也不漏报"的场景
- 但需要控制假阳性

### 4. GBT 和 RF 几乎相同
- 都是 tree-based ensemble
- 计算成本 GBT > RF，选 RF

## 跨属场景：LR 反而更好

在 [[../experiments/多属扩展]] 中发现：
- Strep→Pseudomonas: LR=0.974 > RF=0.950
- 可能原因：LR 在 OOD 场景下更不容易过拟合训练集特定模式

**启示**：对于发现新颖BGC（OOD场景），LR 可能更稳健。
